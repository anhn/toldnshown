# GPT-6-luna replication (to be added)

Records of the replication with GPT-6-luna (low reasoning effort, ChatGPT agents) go here:
one row per run with set, rule, code state, condition (rule removed/present), repetition, verdict and judge reason,
plus the diffs. The paper's GPT counts (212 runs; 68 of 106 pairs judged in both conditions) come from these runs.
Put the run records here as runs.json, in the same format as ../code_variant_set/runs.json.
Then `code/` can analyse them like the Claude runs: `python -m rab analyze`.
